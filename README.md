
# ✨ ListingLift — Make Every Product Shine

**Good products deserve great words.**

ListingLift is a lightweight, beginner-friendly web application designed to help small business owners, independent sellers, and side hustlers create compelling product listings without struggling to find the right words.

From product titles to descriptions and social media captions, ListingLift helps turn simple product details into polished, ready-to-edit marketing copy.

## 🌟 Features

- **Product Title Generator** — Create clear, descriptive product titles.
- **Product Description Writer** — Turn product features into engaging descriptions.
- **Social Media Captions** — Generate promotional captions with relevant hashtags.
- **Multiple Writing Styles** — Choose between Friendly, Playful, Professional, and Luxury tones.
- **One-Click Copy** — Copy generated content for use in your store or social media.
- **Regenerate Options** — Explore alternative versions of your listing.
- **Responsive Design** — Use the application on desktop, tablet, or mobile.
- **Privacy-Friendly Prototype** — No account or backend server is required for the current version.

## 💡 Why ListingLift?

Small businesses often have great products but limited time, marketing experience, or resources to create professional product copy.

ListingLift aims to make product marketing more accessible by providing a simple workspace where sellers can enter their product details and get a useful first draft in seconds.

The goal is simple: **help small sellers spend less time writing and more time building their businesses.**

## 🛠️ Built With

- **HTML5** — Page structure and accessible form elements
- **CSS3** — Responsive layouts, gradients, animations, and visual styling
- **Vanilla JavaScript** — Form handling, text generation, writing styles, and clipboard interactions
- **Google Fonts** — DM Sans and Manrope typography

No frontend framework or package installation is required.

## 🚀 Getting Started

### Prerequisites

You only need:
- A modern web browser
- A code editor such as Visual Studio Code

### Installation

**1. Clone the repository**

Replace the URL below with your actual GitHub repository URL.

```bash
git clone https://github.com/YOUR-USERNAME/ListingLift.git
```

**2. Open the project folder**

```bash
cd ListingLift
```

**3. Open the project**

Open `index.html` directly in your browser, or use the Live Server extension in Visual Studio Code.

That's it! You can start creating product listings immediately.

## 🧭 How to Use

1. Open ListingLift in your browser.
2. Enter the name of your product.
3. Select the appropriate product category.
4. Describe the product's key features.
5. Choose a writing style that matches your brand.
6. Click **Generate my listing**.
7. Copy the title, description, or caption.
8. Regenerate a version if you want to explore a different approach.

Review and edit the generated content before publishing it.

## 🧪 Current Implementation

The current version is a **client-side prototype**.

It uses JavaScript templates to generate product titles, descriptions, and captions based on the information entered by the user. It does not currently call an external AI service or run an open-weight language model.

This keeps the prototype easy to run, test, and contribute to without requiring API keys, model downloads, or a backend server.

The current prototype processes listing details in the browser and does not intentionally send them to a backend server.

The Google Fonts stylesheet may request font resources from Google's servers when an internet connection is available.

If a remote AI model or backend is added in the future, its data-handling behavior should be documented separately.
